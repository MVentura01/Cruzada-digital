+++# Cruzada Digital
+++
+++Jogo de palavras cruzadas desenvolvido como atividade da disciplina de Arquitetura Computacional.
+++
+++## Objetivo
+++Criar uma cruzadinha educacional com 12 palavras relacionadas a arquitetura de computadores, utilizando apenas HTML, CSS e JavaScript puro.
+++
+++## Como rodar
+++Abra `Cruzada-digital/index.html` em um navegador moderno. O projeto é compatível com publicação via GitHub Pages.
+++
+++## Estrutura inicial (Commit 1)
+++- `index.html` — estrutura básica da página e placeholders para tabuleiro, pistas e controles.
+++- `style.css` — estilos base (placeholder). Estilização completa será adicionada no Commit 4.
+++- `script.js` — script inicial (placeholder). Lógica completa será adicionada no Commit 5.
+++- `GRID_PLAN.md` — documento de planejamento do tabuleiro (será adicionado no Commit 2).
